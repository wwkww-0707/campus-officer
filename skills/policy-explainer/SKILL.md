# 政策解读 Skill

## 适用场景

用户咨询校内政策、奖助学金、资助认定、选课与学籍规定，或需要一份办事所需的材料清单与时间表。

## 核心原则：可核验，不编造

这是本 Skill 最重要的约束。政策类回答一旦出错，学生可能因此错过申报或提交错误材料，后果直接。

1. **一切结论必须有出处**——每个政策结论都要带上 `文号` 与 `生效日期`；
2. **知识库里没有的，就明确说没有**——不要用"一般来说""通常"来填补空白；
3. **区分文件性质**——公开真实文件与校内演示样例条款必须在回答中标明；
4. **时效核验**——命中已失效条款时必须降权并提示以官方最新文件为准；
5. **统一合规提示**——回答末尾附"以学校官方最新文件为准"。

## 执行流程

### 第 1 步：判断问题类型

| 问题类型 | 处理方式 |
|---|---|
| "我能申请哪些" | 走资格初筛流程（第 2 步） |
| "某项政策的具体条件/金额/材料" | 走政策检索流程（第 3 步） |
| "什么时候截止" | 走截止时间查询（第 4 步） |
| "这个政策还有效吗" | 走时效核验（第 3 步），重点看 `effective_to` |

### 第 2 步：资格初筛

调用 `get_my_profile` 读取档案（GPA、专业排名、家庭经济困难认定结论），
再调用 `check_eligibility` 按各项目门槛逐项判定。后者返回**判定依据**与待交材料。

回答时必须：
- 先说"符合/不符合"，再说依据；
- 不符合时讲清**差在哪**（哪一项条件没满足）；
- 符合时给出**待交材料清单**，这才是学生真正需要的；
- 金额标注为"示例值"，提醒以官方文件为准。

### 第 3 步：政策条款检索

调用 `search_policy`，必要时补充 MCP 工具 `list_policy_docs` 确认是否有更合适的文件。

**回答格式**：
```
◆ 政策名称
  文号：XXX
  生效期：XXXX-XX-XX 起（现行有效 / 已失效）
  来源：XXX
  关键条款：
  - ……
  ⚠ 该条款已失效，已自动降权，请以学校官方最新文件为准
```

### 第 4 步：截止时间查询

调用 MCP 工具 `get_deadlines`。

**注意**：抽取出来的时间表述往往带"一般""通常"等限定词，转述时**不要去掉这些限定词**，
例如应写"一般于每年 10 月前完成认定（以学校通知为准）"，而不是"10 月截止"。

### 第 5 步：生成材料自检表（用户需要办事时）

调用 `write_artifact` 生成 Markdown 自检表，用 `templates/material_checklist_template.md` 的结构。

## 输出要求

1. 先给结论，再给依据，最后给行动项；
2. 材料清单要可直接照着准备——写成"需要你提交什么"而不是"需要提交相关材料"；
3. 区分"系统已判定"与"需要你线下确认"（如家庭经济困难认定由学校认定，本系统只读取结论）；
4. 绝不代填学生个人信息表，**只生成填写指引**。

## 禁止事项

- 禁止在没有工具返回的情况下描述政策条款内容；
- 禁止把校内演示样例条款说成真实校规；
- 禁止编造截止日期或金额；
- 禁止代替学生填写或提交申请表。
