# 校规与政策条款库

本目录存放**带元数据**的政策条款，采用 Markdown + YAML frontmatter 结构。

每条条款包含 4 个用于溯源与时效核验的关键字段：

| 字段 | 含义 | 作用 |
|---|---|---|
| `doc_number` | 文号 | 让每条结论可被核验，杜绝"编造政策" |
| `effective_from` | 生效日期 | 判断条款是否现行有效 |
| `effective_to` | 失效日期 | 非空且已过期时**自动降权**，并提示以官方最新文件为准 |
| `source` | 来源 | 区分"公开真实文件"与"校内虚构示例条款" |
| `is_sample` | 是否示例条款 | 示例条款在界面与产出物中会显著标注 |

> **重要声明**：`is_sample: true` 的条款为**虚构的校内演示样例**，不对应任何真实学校文件；
> `is_sample: false` 的条款指向教育部/财政部等**公开真实文件**，金额为示例说明值，以官方原文为准。
