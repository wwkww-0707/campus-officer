## 一、5 分钟快速开始

### 1.1 环境要求

| 项目 | 要求 |
|---|---|
| Python | 3.10+（推荐 3.12 / 3.13） |
| 操作系统 | Windows / macOS / Linux |
| 网络 | 首次安装依赖需要；运行期**不需要**（可走规则降级层） |
| API Key | **可选**——不配也能完整演示 |

### 1.2 一键启动（Windows）

```bat
:: 进入项目目录
cd campus-officer

:: 双击或命令行运行
start.bat
```

`start.bat` 会自动完成全部步骤：检查 Python → 缺依赖则安装 → 缺 `.env` 则复制模板 → 启动教务后端（端口 8811）→ 启动 Streamlit 界面（端口 8501）。

### 1.3 手动启动（推荐，便于理解每一步）

```bat
:: 1) 创建虚拟环境
python -m venv .venv
.venv\Scripts\activate

:: 2) 安装依赖
pip install -r requirements.txt

:: 3) 配置环境变量（可选，不配也能跑）
copy .env.example .env
:: 用记事本打开 .env，填入 DASHSCOPE_API_KEY（不填则走规则降级层）

:: 4) 【另开一个窗口】启动教务业务后端
python backend\main.py

:: 5) 【回到原窗口】启动界面
python -m streamlit run app.py
```

浏览器访问 **http://localhost:8501**

### 1.4 macOS / Linux

```bash
chmod +x start.sh && ./start.sh
```

### 1.5 验证是否跑通

界面顶部应显示：
- ✅ 模型接入（绿色，配了 Key 时）或 ⚠️ 规则降级引擎（黄色，未配 Key，仍可正常使用）
- ✅ 教务后端：运行中
- 课程库：12 门

如果后端显示"未连接"，单独运行 `python backend/main.py` 看报错。

## 三、使用方法（5 条演示话术）

界面左上角有「💡 推荐演示话术」卡片，点击「填入」按钮即可。

### 话术 1：选课组合（核心演示）

```
下学期能选哪些课？避开周三下午，挑 3 门最值得上的，别超 20 学分
```

**你会看到**：
1. 🧭 **规划**：智能体把这句话拆成 4 步，每步标注将调用的工具
2. 🔧 **执行**：`list_courses` → `get_my_enrollments` → `write_artifact` 三个工具真实调用，每个带入参、耗时、返回摘要
3. 📄 **结果**：推荐 3 门无冲突课程 + 未选中课程的原因（满员/冲突/避开周三）+ 产出物路径

### 话术 2：奖助学金资格

```
我 GPA 3.6，能申请哪些奖助学金？要交什么材料？什么时候截止？
```

**你会看到**：读档案（`get_my_profile`）→ 逐项比对门槛（`check_eligibility`）→ 汇总待交材料，每项带文号与生效期，末尾附"以学校官方最新文件为准"。

### 话术 3：冲突检测

```
《人工智能导论》和《数据结构与算法》冲突吗？
```

**你会看到**：确定性闭区间求交算法判定，结论可复现——"周二第 1-2 节冲突"。

### 话术 4：学习规划

```
帮我排一份每周学习计划
```

**你会看到**：时间预算子代理，输出四象限周计划（课程复习/竞赛/考研/休息）+ 里程碑 + 风险提示。

### 话术 5：产出物

```
帮我把选课方案整理成一份清单文件
```

**你会看到**：走完一条事务链并生成 `outputs/选课清单_<时间戳>.md`，界面左侧栏可直接下载。

### 待确认操作

当智能体要**选课提交**（写操作）时，会弹出确认条，必须点「✅ 确认执行」才会真正提交。这是"危险操作二次确认"的落点。

## 四、关键实现点

### 4.1 智能体在界面"看得见"：三段式

打开界面就能确认这不是查表机器人。每轮回答固定呈现：

| 段 | 内容 | 证明什么 |
|---|---|---|
| 🧭 规划 | 把一句话拆成 2-4 步，每步标注工具 | 先想清楚再动手 |
| 🔧 执行 | 真实工具调用轨迹（工具名/入参/耗时/返回） | 工具真的被调用 |
| 📄 结果 | 最终答复 + 产出物路径 | 事务有闭环、有留痕 |

**实现**：`core/graph.py` 的 `_plan()` 阶段先产出计划，再注入模型上下文让模型按计划推进。计划持久化到会话，刷新后仍可见。

### 4.2 LLM 规划与规则裁决分离

时间冲突**不由模型目测课程名**，而由 `backend/schedule.py` 的闭区间求交判定：

```python
def slots_overlap(a, b):
    if a.weekday != b.weekday:
        return False
    return a.start_period <= b.end_period and b.start_period <= a.end_period
```

模型负责理解意图与解释结论，算法负责"算"。子代理用回溯搜索在五重约束下求组合。

### 4.3 条款时效核验 + 文号溯源

每条校规带 `文号 / 生效期 / 失效期 / 来源`。检索时过期条款排序分 ×0.25 自动沉底，并标注"已失效，以官方最新文件为准"。知识库里**故意放了一条已失效条款**用于演示该机制。

### 4.4 三层降级链

```
百炼（需 Key） → Ollama（本地） → 规则引擎（零网络零 Key）
```

第 3 层**照样调用同一套真实工具**，保证断网、无 Key 的教室电脑上主路径照常走完。这是"现场演示零翻车"的工程保障。

### 4.5 权限隔离

`core/artifacts.py` 对文件名做显式拒绝：出现 `..`、路径分隔符或盘符时直接抛 `PermissionError`，而不是静默改写。Agent 只能写 `outputs/`。

### 4.6 MCP 服务器

`mcp_server/server.py` 用官方 MCP Python SDK 实现，stdio 传输，3 个工具（`search_policy` / `get_deadlines` / `list_policy_docs`）。可被任意 MCP 客户端复用。

其中 `get_deadlines` 与 `list_policy_docs` 通过 `core/mcp.py` 的**常驻 session 桥接**（后台事件循环线程把异步 stdio 工具包装成同步工具）真实挂载进了智能体——规则引擎的"截止查询"路径就是走 MCP 的 `get_deadlines`，不是本地检索。`search_policy` 因与本地工具同名、能力重叠，智能体用本地版，MCP 版仍对外部客户端开放。

### 4.7 关键代码指认（答辩用）

## 六、常见问题

### Q1：没有 DASHSCOPE_API_KEY 能用吗？

能。系统会自动切换到规则降级引擎，工具调用与业务数据仍为真实，只是语言回复为模板化。在 `.env` 中配 Key 后重启可获得自然语言交互。

### Q2：界面显示"教务后端：未连接"

单独运行 `python backend/main.py`，看是否有报错。常见原因：依赖未装、端口被占用。换端口：修改 `.env` 的 `CAMPUS_API_BASE_URL`。

### Q3：如何切换到本地 Ollama？

在 `.env` 中设置：
```
LLM_PROVIDER=ollama
OLLAMA_MODEL=qwen2.5:7b
```
确保本机已 `ollama pull qwen2.5:7b`。

### Q4：产出物在哪里？

`outputs/` 目录。界面左侧栏「📦 产出物」可直接下载。文件名带时间戳。

### Q5：如何添加新课程？

编辑 `backend/seed.py` 的 `SEED_COURSES`，删掉 `data/campus.db`，重启后端会自动重建。

### Q6：幻灯片打不开？

`docs/presentation.html` 是零外链单文件，双击即可在浏览器打开。键盘 ←/→ 翻页，空格下一页。
