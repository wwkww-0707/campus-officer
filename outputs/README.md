# outputs —— 产出物目录

本目录是 **Agent 唯一允许写入**的目录（权限隔离的实现落点）。

## 为什么单独隔离

《期末考查要求》的加分项提到"权限隔离（Agent 只能写指定目录）"。本项目的实现是：

1. `core/artifacts.py` 的 `ArtifactWriter._resolve_safe()` 对文件名做**显式拒绝**——
   出现 `..`、路径分隔符或盘符时直接抛 `PermissionError`，而不是静默改写；
2. 文件名经 `sanitize_filename()` 清洗（去除非法字符、规避 Windows 保留设备名）；
3. 解析后的绝对路径必须仍位于本目录之内（`is_relative_to` 校验），防符号链接绕过。

对应测试见 `tests/test_eligibility_and_artifacts.py::TestArtifactSafety`。

## 会生成什么

| 文件类型 | 内容 |
|---|---|
| `选课清单_*.md` | 推荐课程、学分合计、冲突检测结论、**未选中课程及原因** |
| `奖助学金材料自检表_*.md` | 可申请项目、逐项判定依据、材料打勾清单、时间节点 |
| `学期学习计划_*.md` | 每周时间四象限分配、里程碑、风险提示 |
| `课程日历_*.ics` | 可导入日历软件的课程与学习任务 |
| `事务日志_*.json` | 本次会话所有工具调用与参数的留痕 |

所有产出物均带页脚声明：*基于演示用虚构样例数据生成，仅供参考，以学校官方最新文件为准。*

> 本目录内容已被 `.gitignore` 排除（保留 `.gitkeep`），避免把生成的文档提交进仓库。
